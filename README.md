# Sec-X: AI Security Research Documentation

A comprehensive documentation website focused on AI security research, vulnerabilities, and mitigation strategies. Built in the style of HackTricks, this repository contains detailed documentation about various AI security techniques and their implications.

## Topics Covered

- Jailbreaking Techniques
- Prompt Injection Methods
- Token Manipulation
- System Vulnerabilities
- And more...

## Website Structure

```
.
├── index.html              # Main landing page
├── assets/                 # Static assets
│   ├── css/               # Stylesheets
│   │   ├── style.css      # Base styles
│   │   ├── technique.css  # Technique page styles
│   │   └── mobile.css     # Responsive design
│   └── js/                # JavaScript files
│       ├── main.js        # Core functionality
│       └── technique.js   # Technique page scripts
└── techniques/            # Documentation pages
    └── jailbreaking.html  # Jailbreaking techniques
```

## Features

- 🌓 Dark/Light theme toggle
- 📱 Mobile-responsive design
- 🔍 Search functionality
- 📋 Code syntax highlighting with copy functionality
- 📑 Table of contents with smooth scrolling
- 📊 Technique metadata display
- ⚠️ Security notes and warnings

## GitHub Pages Setup

1. Go to repository Settings
2. Navigate to Pages section
3. Select 'main' branch as source
4. Choose '/ (root)' as the folder
5. Click Save

The site will be available at: `https://[your-username].github.io/sec-x/`

## Local Development

To preview the site locally:

1. Clone the repository
2. Open `index.html` in your web browser
