# Sec-X: AI Security & LLM Prompts

A comprehensive resource for understanding and defending against prompt injection attacks in AI systems. This documentation focuses on security vulnerabilities, attack vectors, and mitigation strategies in Large Language Models (LLMs).

## 🌐 Website

Visit our documentation at: [https://[username].github.io/sec-x](https://[username].github.io/sec-x)

## 📚 Content

The documentation covers:

- Introduction to Prompt Injection
- Types of Prompt Injection Attacks:
  - Hallucination Injection
  - Time Traversal Injection
  - Roleplay Injection
- Mitigation Strategies

## 🚀 Local Development

1. Clone the repository:
```bash
git clone https://github.com/[username]/sec-x.git
cd sec-x
```

2. Open `index.html` in your browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

3. Visit `http://localhost:8000` in your browser
